#  PIGGO：整合行程管理與社群分享的智慧旅遊應用系統
## 前言
要讓一群人順利出遊，從來不只是把行程安排好這麼簡單。從出發前的意見整合、旅途中的即時協助再到返程回憶分享，整個旅程都需要不斷溝通與協調。然而，現有App多半偏重行前規劃，且使用者需頻繁切換多個工具，導致操作流程零碎。為此，我們開發PIGGO智慧旅遊App，以AI輔助與自動化協作為核心，完整涵蓋旅行「前、中、後」，自動化處理繁雜排程與事實查證，減輕旅伴負擔，讓多人出遊真正輕鬆順暢。

## 創意描述
### 1. AI隨行協助：從動態排程到拍照指導
* **演算法與推薦機制**：系統透過「旅行人格測驗」量化喜好標籤，並在後端進行邏輯運算與排序：綜合考量群組成員偏好的交集，同時串接Google Maps API計算景點間的距離與交通時間，由系統自動過濾並篩選出兼顧「大家喜好」與「路徑順暢」的推薦行程順序。
* **即時應變與拍照指導**：串聯OpenWeatherMap氣象API與營業狀態監控，當偵測到突發狀況時主動發出預警並提供鄰近備案；拍攝時則串聯LBS定位與AI視覺辨識，系統主動識別環境，於畫面即時疊加「人物輔助線」，並提供動態的「姿勢微調提示」，將AI協助延伸至實際旅遊情境。另外，拍攝後可一鍵同步至群組共享相簿，解決多人旅行結束還要收集與整理照片的困擾。

### 2. 全流程整合：讓規劃、出遊與分享相互銜接

* **資料流串接**：串聯行程安排、行李準備、旅途提醒與共享相簿。當群組成員完成投票後，Node.js後端會即時將結果寫入資料庫，自動篩選最高票景點並透過Google Maps API串接成地圖路線。此外，在共享相簿中，系統更支援人臉辨識，讓成員能一鍵快速篩選出包含自己的旅遊照片，解決傳統相簿尋找耗時的困擾。
* **便利分享機制**：支援將他人分享的旅遊行程一鍵匯入個人計畫中，實現流暢的社群互動與行程共用體驗。

### 3. 多人協作互助：讓每位旅伴都能參與

* **行前共編決策**：整合偏好分析、景點投票、行程共編與行李清單認領，將零散的群組意見透過系統自動轉化為具體安排；AI亦會根據目的地氣候智慧推薦攜帶物品。
* **旅途RAG事實查證**：旅途中若遇突發狀況可向附近或相關使用者提問，系統採用RAG架構，結合即時網路搜尋與Google Places API抓取上下文進行摘要與事實比對，協助使用者即時判斷與應變。

## 系統功能簡介

1. **旅行人格測驗**：AI根據結果給出對應偏好標籤，並推薦行程與景點。
2. **計畫**：創建群組後，可以多人共同編輯行程、共享行李清單，群組投票、聊天等。AI也會計算群組的偏好標籤最大交集，來進行景點推薦。
3. **相機**：提供內建相機拍攝、AI拍照指導及共享相簿功能。系統會分析環境，並透過畫面的輔助線與即時骨架提示來提供構圖與姿勢建議。
4. **交流**：分兩個版面。「推薦版」分享與瀏覽他人的旅遊行程，並可一鍵匯入到自己的行程中；「問答版」旅遊遇到突發狀況時可即時提問，並由附近及相關用戶解答，另外，AI會自動統整摘要留言，並進行事實查證。
5. **全域AI助手**：負責比對店家營業時間與建議景點順序、提醒旅行中的天氣與下一個行程的時間。

## 系統特色

### 1. 整合群組決策，降低工具切換與資訊落差

* **差異優勢**：市面上的工具往往讓使用者在通訊軟體、記事本和地圖App間來回切換。PIGGO的核心價值在於將投票到產生路線全部結合在同一個 App 內，解決多人出遊時因工具分散造成的資訊落差。

### 2. 氣象與異常的主動預警

* **差異優勢**：多數旅遊App只會在使用者主動搜尋時提供資訊，其仍需自行判斷這些變化是否會影響行程。PIGGO則會結合天氣、交通與景點營業狀態，當偵測到可能影響行程的情況時，會主動提醒並提供替代景點或調整順序，將即時資訊轉化為可執行的應變方案。

### 3. 突發狀況的動態應變與協助

* **差異優勢**：多數工具只提供排定的行程時間，一旦遇到延誤或突發狀況常讓人不知所措。PIGGO不僅幫忙排定行程，當行程延誤時也能即時給予替代方案，更透過問答互助與RAG機制快速提供解答。

## 系統開發工具與技術

1. **開發工具**：Visual Studio Code、Xcode/iOS、Flutter/Dart、Node.js/Express、MySQL 資料庫、Aiven 雲端資料庫、AWS S3 雲端儲存。
2. **開發技術**：
* **交通運輸服務**：整合交通部TDX台鐵與高鐵時刻表API，支援全台班次查詢、時刻動態抓取與跨運具轉乘規劃。
* **地理資訊與地圖服務**：整合Google Maps與OpenWeatherMap API，支援地點查詢、路徑串接，及氣象環境監控與狀態觸發。
* **狀態管理與網路請求**：前端使用Provider進行狀態管理，並透過HTTP套件與後端API溝通，確保多人協作時資料更新與畫面同步。
* **AI 語意輔助與推薦**：後端透過LLM與提示詞工程，對使用者與群組成員的偏好標籤進行語意解析、交集計算與邏輯排序，生成智慧推薦。
* **RAG 事實查證**：針對問答版與即時資訊查詢，系統結合即時網路搜尋與Google Places API上下文輸入，限制AI依引文進行摘要與比對，確保資訊正確性並避免幻覺。



## 系統使用對象

PIGGO 主要針對喜愛結伴出遊、追求高效率與智慧化規劃的使用者：

1. **群組出遊者**：
* **痛點**：經常面臨多人意見分歧、行程規劃繁瑣、分工混亂以及旅途中突發狀況多（如天氣變化、記帳分帳麻煩）的困擾。
* **需求**：希望有一個能整合「討論、投票、排程、行李協作與即時工具」的單一平台，降低行前溝通成本。


2. **注重效率的自由行規劃者**：
* **痛點**：每次排行程都要手動查地圖、對營業時間，一旦臨時加景點就要重排，耗費大量心力。
* **需求**：希望透過智慧輔助（如個人偏好匹配、動態行程最佳化、氣象預警），自動化處理繁雜的計算與排程，讓旅遊規劃更輕鬆省時。



## 系統使用環境

1. **行動裝置系統**：Android 7.0 以上或 iOS 13 以上
2. **開發與運行環境**：支援跨平台行動應用程式開發框架，並搭配後端雲端服務與資料庫，確保多人即時協作的穩定與流暢度。

## 結語

PIGGO 以「AI 智慧輔助」為核心，從行前的群組決策、行中的動態行程最佳化與氣象預警，到全方位的共編與拍照指導，大幅提升了團隊協作效率。透過人機協作，PIGGO 不僅降低了旅伴間的溝通摩擦與時間成本，更串聯了從決策到執行的完整體驗。

## 系統使用指南

1. **初始化與測驗**：首次開啟 APP 完成註冊後，系統會自動引導進入「旅行人格測驗」，請依直覺作答以利 AI 建立初始偏好模型。

2. **建立群組與計畫**：進入【計畫】分頁，邀請好友加入群組。在聊天室中，系統會依據群組成員的偏好交集，推送 AI 行程卡片。

3. **無縫決策**：點擊 AI 卡片下方的「加入投票選項」，即可在聊天室內發起表決。確認後的景點將自動同步至團隊行程表。

4. **行中儀表板**：旅遊當日切換至【首頁】，系統會依據行程表自動提供下一站導航、當下匯率與分帳工具，並透過 AI 推播天氣警告。
